# Electricity Consumption Analysis

## Project Overview
This project analyses electricity consumption data using SQL and Tableau. It helps identify consumption patterns, trends, and insights through interactive dashboards.

## Tools Used
- SQL
- Tableau
- CSV Dataset

## Files
- csv file.csv – Dataset
- sql operations.sql – SQL queries
- energy consumption project.twb – Tableau dashboard
- project report.pdf – Project documentation

## Features
- Data cleaning using SQL
- Interactive Tableau dashboards
- Trend and consumption analysis
- Visual reports
